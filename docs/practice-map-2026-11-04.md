# 实践地图与红色割草机标识

用“实践地图”替换按年月分组的归档，入口为`/practice/`。按资料治理、知识检索、训练实验、应用交付组织现有12篇实践文章，并保留开篇入口。每条主线包含一个具体问题、文章阅读提示和一条个人体会；页面不展示发表日期。
