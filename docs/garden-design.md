# 戴夫的庭院后备箱

日期：2026-11-04。目标为生动、有动画和少量互动的《植物大战僵尸》式个人博客，直接用戴夫的汽车后备箱展示真实内容。

- 首页采用绿色车尾：抬起的棚盖、木招牌、深色货厢、纸质种子卡、木层架、尾灯、轮胎、车牌与保险杠。货厢默认打开，文章无需通过装饰交互解锁。
- 每张纸卡展示真实文章标题、摘要、日期与栏目或标签，链接仍由 Markdown 文件名生成。最多显示六篇，不增加虚构文章、统计或固定栏目。
- 庭院背景及戴夫、向日葵、豌豆射手由内置 `image_gen` 生成；四个 WebP 合计约 591 KiB，透明角色保留 alpha。完整提示词与文件路径见 [素材记录](art-prompts-pvz.md)。
- 植物与云朵持续缓慢运动，钥匙轻摆；卡片悬停轻抬。系统减少运动时采用更慢的小幅运动；标签页隐藏时暂停庭院的循环动画。
- 点击阳光增加 25，分数在当前浏览器会话保留；点击豌豆射手发射豌豆，击中纸板僵尸会轻晃；点击戴夫出现短暂气泡；点击车牌摇动招牌、钥匙并点亮尾灯。所有按钮支持键盘操作，不要求这些互动才能阅读文章。
- 手机上车厢随纸卡纵向展开，戴夫缩小到棚盖旁。正文、搜索、栏目与归档使用奶油纸张面板，优先保持阅读清楚。

后备箱的层架布局参考了 [Crazy Dave 商店游戏画面](https://monstervine.com/2010/02/plants-vs-zombies-review-iphone-edition/)；本站没有直接使用游戏截图作为背景。框架仍为 Astro，内容仍由作者通过 GitHub Markdown 管理，栏目转移仍只修改原文的单值 `column`。
